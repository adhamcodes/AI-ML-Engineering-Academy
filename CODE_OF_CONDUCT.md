# Community Conduct

Be constructive, specific, and respectful. Critique ideas, code, and curriculum design rather than people. Do not harass, demean, threaten, or discriminate against contributors or learners.

This project is intended to help serious learners improve. Gatekeeping, credential-shaming, and mocking beginner questions are not useful contributions.

For public discussions, avoid posting private learner information, credentials, client data, or assessment solutions that defeat the learning design.
