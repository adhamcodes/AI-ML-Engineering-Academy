# Parallel Study and Prerequisite Gates

This academy is meant to run beside normal software-engineering study, not replace it.

## Git/GitHub

Complete the core of `adhamcodes/git-github-course` early. By the time you reach serious project, MLOps, and collaboration work here, Git status/diff/commits/branches/remotes/recovery should feel normal.

## Before Phase 2 — Scientific Python & Data

You should already be able to write and debug ordinary Python using functions, modules, collections, files, exceptions, virtual environments, and basic tests.

If not, repair that software-engineering prerequisite before treating NumPy/Pandas syntax as the problem.

## Before Phase 4 — Deep Learning & PyTorch

You should be comfortable reading unfamiliar Python code, tracing shapes/state through functions, writing tests, and using Git branches for experiments.

## Before Phase 9 — MLOps & Production AI

You should already understand HTTP basics, automated tests, environment/configuration separation, containers conceptually, and ordinary debugging.

## Automation overlap

The Automation academy can run in parallel. Share concepts such as APIs, evaluation, observability, agents, and production reliability—but keep each academy's mastery gates separate so familiarity in one track does not become fake evidence in another.

The rule is simple: **when a prerequisite is missing, repair it instead of hiding it with a tutorial or generated solution.**
