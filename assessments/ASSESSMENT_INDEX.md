# Assessment Index

Major phase gates are located in each phase's `ASSESSMENT.md` (or final gate module where applicable).

Assessment modes deliberately mix:
- explanation/prediction;
- reconstruction from a blank file;
- debugging broken systems;
- transfer to unfamiliar data/tasks;
- project acceptance criteria;
- closed-assistance gates;
- later professional-mode projects where AI tools are allowed but must be reviewed/tested.

If a gate fails, repair the specific weakness and re-test it. Do not repeat an entire phase unless the failure is broad.
