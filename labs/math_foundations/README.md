# Math-to-Code Lab

Use `vector_projection.py` to connect algebra, geometry, and code without a large framework.

Tasks:

- compute dot products by hand and in code,
- predict whether vectors are orthogonal,
- compute a projection,
- explain what changes when the basis vector is scaled,
- connect projection error to the idea of residual error.

Run `test_vector_projection.py` after your reasoning, not before.
