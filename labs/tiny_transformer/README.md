# Tiny Transformer Lab

This is the executable starter for Phase 6.

Implement the missing functions in `starter.py` in this order:

1. causal mask,
2. scaled dot-product attention,
3. single-head self-attention forward pass.

Then run `test_contract.py`.

The tests target the exact failure modes the curriculum discusses: shape correctness, causal masking, softmax dimension behavior, and deterministic outputs with fixed inputs.

Use `HINTS.md` progressively. Do not jump to the last hint first.
