# AI/ML Engineering Labs

This directory is the executable layer of the academy.

Rules:

- work on copies in your own implementation repository,
- freeze train/validation/test boundaries before tuning,
- never repair an evaluator just to make a result pass,
- record failed experiments as evidence,
- use tiny controlled data first, then scale only when the concept is understood,
- keep solutions out of this canonical repository where an assessment depends on independent work.

Install optional framework dependencies with `requirements-labs.txt` when a lab needs them.
