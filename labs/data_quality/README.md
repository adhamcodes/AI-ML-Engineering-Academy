# Data Quality Lab

`messy_customers.csv` is deliberately small but dirty.

Find and document:

- duplicate entities,
- missing values,
- inconsistent categories,
- impossible ages,
- inconsistent date formats,
- a field that should not be silently coerced.

Create a cleaning script in your own repo that preserves a raw copy, records every rule, and produces a reproducible cleaned dataset plus a data-quality report.
