# Diagnostic Lab

Before Phase 1, create a baseline without assistance for:

- Python functions, loops, dictionaries, files,
- basic algebra and functions,
- vectors/matrices vocabulary,
- mean/variance intuition,
- reading a small table,
- explaining train vs test data.

Record `can explain`, `can do with hints`, or `cannot yet do`. This is routing evidence, not a grade. Re-run the same diagnostic after major milestones to measure actual change.
