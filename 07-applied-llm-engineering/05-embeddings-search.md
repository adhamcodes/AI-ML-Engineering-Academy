# Module 07.5 — Embeddings & Semantic Search

## Capability
Build and evaluate semantic retrieval baselines.

## Mental model / core ideas
Embedding models map items/queries to vectors; index/search choices and domain alignment determine retrieval quality.

## Practice
Create a small corpus/query set and calculate recall@k/MRR-like measures.

## Debugging / transfer task
Find a query where lexical search beats semantic search.

## Build evidence
Build semantic + lexical baselines.

## Mastery check
You can measure rather than eyeball retrieval.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
