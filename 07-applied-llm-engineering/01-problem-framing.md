# Module 07.1 — LLM Problem Framing & Baselines

## Capability
Decide whether an LLM is justified and define measurable success.

## Mental model / core ideas
Start with user/job-to-be-done, failure cost, data/privacy constraints and a non-LLM or simple-prompt baseline.

## Practice
Write success metrics and unacceptable-failure cases for three use cases.

## Debugging / transfer task
Reject an LLM solution where deterministic search/rules are better.

## Build evidence
Create an experiment charter before implementation.

## Mastery check
Success is measurable independently of demo impressiveness.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
