# Module 07.17 — Employment Gate — Junior Applied AI Ready

## Capability
Demonstrate independent applied-AI judgment on an unfamiliar specification.

## Mental model / core ideas
You must frame, baseline, design evals, build a thin system, diagnose failures and defend tradeoffs.

## Practice
Closed-assistance core design/eval exercise; professional implementation may use AI tools only after your plan is recorded.

## Debugging / transfer task
Unexpected retrieval and structured-output defects are introduced.

## Build evidence
Submit architecture/eval evidence and a repair log.

## Mastery check
Pass earns **Junior Applied AI Ready**, not “finished learning AI.”

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
