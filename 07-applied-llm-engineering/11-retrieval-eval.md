# Module 07.11 — Retrieval Evaluation

## Capability
Measure whether the system finds the right evidence.

## Mental model / core ideas
Use labeled relevant docs/chunks where possible and metrics such as recall@k, precision@k, rank measures plus qualitative error taxonomy.

## Practice
Score retrieval under several configurations.

## Debugging / transfer task
Diagnose high generation quality hiding poor retrieval coverage.

## Build evidence
Create retrieval dashboard/table.

## Mastery check
You can distinguish retrieval recall and ranking problems.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
