# Module 07.3 — Prompt/System Instruction Design

## Capability
Write stable instructions and input contracts without confusing prompt tweaks with system quality.

## Mental model / core ideas
Prompts define behavior/context but cannot guarantee facts, permissions or reliable structured state.

## Practice
Create versioned prompt templates and test adversarial/ambiguous inputs.

## Debugging / transfer task
Repair prompt injection/role confusion or brittle formatting.

## Build evidence
Maintain prompt tests like code regression tests.

## Mastery check
You can state what must be enforced outside the prompt.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
