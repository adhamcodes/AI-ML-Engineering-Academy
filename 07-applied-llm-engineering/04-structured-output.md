# Module 07.4 — Structured Outputs & Validation

## Capability
Turn probabilistic text into validated machine-consumable data.

## Mental model / core ideas
Use schemas/typed validation, constrained outputs where available, retries/fallbacks and explicit error paths.

## Practice
Extract structured records from noisy inputs; validate types/enums/ranges.

## Debugging / transfer task
Handle malformed/partial/refusal output without crashing downstream workflow.

## Build evidence
Build a validated extraction API.

## Mastery check
No downstream code trusts raw model prose.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
