# Phase 7 — Applied LLM Engineering

**Typical effort:** ~6–8 weeks

## Purpose
Turn foundation knowledge into measurable, reliable LLM systems: RAG, structured outputs, evaluation, grounding, operational tradeoffs and security.

## Modules
1. LLM Problem Framing & Baselines
2. Model & Provider Selection
3. Prompt/System Instruction Design
4. Structured Outputs & Validation
5. Embeddings & Semantic Search
6. Vector Indexes & Metadata
7. RAG Pipeline Anatomy
8. Chunking, Metadata & Document Boundaries
9. Hybrid Retrieval & Reranking
10. Evaluation Datasets
11. Retrieval Evaluation
12. Generation Evaluation
13. Grounding, Citations & Abstention
14. Cost, Latency, Caching & Routing
15. LLM Security & Data Boundaries
16. Flagship — Evaluated Applied LLM System
17. Employment Gate — Junior Applied AI Ready

## Gate
Pass **Junior Applied AI Ready** by shipping and defending an evaluated system on unfamiliar requirements.
