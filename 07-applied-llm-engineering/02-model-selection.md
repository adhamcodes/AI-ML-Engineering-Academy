# Module 07.2 — Model & Provider Selection

## Capability
Compare models by quality, latency, cost, context, privacy and deployment constraints.

## Mental model / core ideas
Model choice is a systems decision. Bigger is not automatically better; route tasks to the cheapest model that satisfies measured requirements.

## Practice
Build a small comparison harness across two models or model sizes.

## Debugging / transfer task
Find benchmark overfitting: a model wins public score but fails your domain set.

## Build evidence
Write a model-selection decision record.

## Mastery check
Decision is supported by your eval set and operational constraints.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
