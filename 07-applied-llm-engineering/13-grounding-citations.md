# Module 07.13 — Grounding, Citations & Abstention

## Capability
Design systems that show evidence and decline unsupported answers.

## Mental model / core ideas
Grounding requires retrieved/supporting evidence plus generation behavior and verification; citations must actually support claims.

## Practice
Create citation-support checks and no-evidence cases.

## Debugging / transfer task
Find a citation that points to retrieved text but does not support the claim.

## Build evidence
Add abstention/insufficient-evidence paths.

## Mastery check
System prefers honest failure to invented certainty.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
