# Module 07.12 — Generation Evaluation

## Capability
Evaluate free-form outputs systematically with deterministic and model-assisted scorers.

## Mental model / core ideas
Combine exact/programmatic checks, task-specific rubrics, human review and calibrated LLM judges; no single judge is ground truth.

## Practice
Build a scoring harness for correctness/relevance/format/citation behavior.

## Debugging / transfer task
Expose judge bias with adversarial or swapped answers.

## Build evidence
Create regression tests around known failures.

## Mastery check
Evaluation claims include scorer limitations.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
