# Module 06.4 — Multi-Head Attention

## Capability
Explain why several learned attention subspaces can coexist.

## Mental model / core ideas
Heads use different projections, enabling parallel relational patterns; outputs are concatenated/projected. More heads do not automatically mean better reasoning.

## Practice
Trace per-head dimensions and recombination.

## Debugging / transfer task
Repair a head-dimension mismatch.

## Build evidence
Visualize head outputs on a toy example without claiming they are explanations.
