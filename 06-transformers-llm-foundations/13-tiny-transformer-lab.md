# Module 06.13 — Tiny Transformer Lab

## Capability
Integrate tokenizer/data/model/training understanding by building a small transformer component/system.

## Mental model / core ideas
Small-scale implementation exposes hidden assumptions without pretending to recreate frontier models.

## Practice
Implement attention/block/tiny LM pieces; run shape/unit tests and a tiny training experiment.

## Debugging / transfer task
Inject masking/target-shift/shape bugs and repair them.

## Build evidence
Submit code, tests, loss curve and limitations note.

## Mastery check
Every component is explainable from first principles.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
