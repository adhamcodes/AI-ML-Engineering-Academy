# Module 06.14 — Transformer Foundations Assessment

## Capability
Demonstrate transformer/LLM understanding without relying on library recipes.

## Mental model / core ideas
The assessment combines explanation, tensor tracing, debugging and architecture choices.

## Practice
Closed-assistance: compute attention shapes, explain objectives/decoding and inspect a broken tiny transformer.

## Debugging / transfer task
Repair mask/target/tokenizer/inference issues.

## Build evidence
Produce a concise technical walkthrough.

## Mastery check
Pass only if you can explain mechanics and practical consequences.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
