# Module 06.9 — Decoding & Sampling

## Capability
Control generation and explain greedy, temperature, top-k/top-p and repetition effects.

## Mental model / core ideas
The model produces a probability distribution; decoding is a separate policy for selecting tokens.

## Practice
Compare deterministic and stochastic decoding on fixed prompts.

## Debugging / transfer task
Diagnose bad evaluation caused by uncontrolled sampling.

## Build evidence
Create a decoding comparison harness.

## Mastery check
Explain quality/diversity/reproducibility tradeoffs.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
