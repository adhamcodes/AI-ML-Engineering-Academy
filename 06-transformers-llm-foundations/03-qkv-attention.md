# Module 06.3 — Queries, Keys, Values & Self-Attention

## Capability
Compute and explain self-attention mechanics.

## Mental model / core ideas
Queries ask what information is relevant; keys describe what positions offer; values carry content. Similarity scores are scaled, normalized and used to mix values.

## Practice
Compute a tiny attention matrix by hand and in code.

## Debugging / transfer task
Diagnose wrong softmax dimension or masking.

## Build evidence
Implement single-head attention for toy tensors.

## Mastery check
Derive shapes and explain masking/normalization.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
