# Module 06.7 — Encoder, Decoder & Encoder–Decoder Families

## Capability
Match transformer family to task and training objective.

## Mental model / core ideas
Encoders build bidirectional representations; decoders autoregress; encoder–decoder models condition generation on an encoded input.

## Practice
Classify common task patterns and choose family.

## Debugging / transfer task
Explain why causal decoder may be inefficient for simple embeddings/classification.

## Build evidence
Write architecture-choice notes for three tasks.

## Mastery check
Choose based on objective, not brand name.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
