# Phase 1 — Mathematical Foundations for Machine Learning

**Expected effort:** roughly 4–6 weeks for a learner rebuilding mathematics from near-zero. Take longer if the mastery gate says you need it.

## Purpose
This phase is not a mathematics degree compressed into a month. It builds the exact mathematical language you need to understand later ML instead of treating formulas as magic.

## Learning arc
1. Algebra, notation, exponents/logs, summations
2. Functions and graphs
3. Vectors and matrices
4. Dot products, norms, linear combinations
5. Matrix multiplication and transformations
6. Systems, span, basis, rank intuition
7. Eigenvalues/eigenvectors and decompositions intuition
8. Probability, conditional probability, Bayes
9. Random variables and distributions
10. Expectation, variance, covariance, independence
11. Samples, estimation, uncertainty
12. Correlation and bias/variance thinking
13. Derivatives and partial derivatives
14. Gradients, chain rule, loss surfaces
15. Gradient descent and optimization
16. Phase mastery gate

## Rule
Always connect symbol → meaning → computation → ML use.

You are allowed to be rusty. You are not allowed to memorize notation you cannot explain.
