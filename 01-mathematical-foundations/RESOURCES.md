# Phase 1 Resource Map

The academy provides the path and applied context. These resources provide additional explanation and serious practice.

## Algebra/functions — Primary practice reference
**OpenStax College Algebra 2e**  
https://openstax.org/books/college-algebra-2e/pages/preface

Use selectively:
- Chapters 1–2 only where diagnostic reveals gaps;
- Chapter 3 for functions/function notation;
- Chapter 4 for linear functions;
- Chapter 6 for exponential/logarithmic functions;
- Chapter 7 only for systems material needed here.

Do not read cover-to-cover unless you genuinely need the remediation.

## Mathematical ML bridge — Primary reference
**Mathematics for Machine Learning — Deisenroth, Faisal, Ong**  
https://mml-book.github.io/

Phase 1 mapping:
- Ch. 2 Linear Algebra
- Ch. 3 Analytic Geometry selectively
- Ch. 4 Matrix Decompositions for intuition, not proof mastery
- Ch. 5 Vector Calculus
- Ch. 6 Probability and Distributions
- Ch. 7 Continuous Optimization

The book assumes more comfort than a true beginner. Use academy modules/OpenStax to enter it rather than fighting every page immediately.

## Linear algebra intuition
**3Blue1Brown — Essence of Linear Algebra**  
https://www.3blue1brown.com/topics/linear-algebra

Use for visual intuition around vectors, transformations, matrix multiplication, determinant/eigen ideas. It supplements exercises; it does not replace them.

## Linear algebra rigorous practice
**MIT OpenCourseWare 18.06 — Linear Algebra**  
https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/

Use selected lectures/problems on:
- geometry of linear equations;
- matrix operations;
- vector spaces/basis/dimension;
- orthogonality where useful;
- eigenvalues/eigenvectors;
- linear transformations.

The course includes problem sets and exams with solutions. Do not attempt every advanced topic before Phase 2.

## Probability/statistics
**OpenStax Introductory Statistics**  
https://openstax.org/books/introductory-statistics/pages/preface

Use selected chapters:
- sampling/data;
- descriptive statistics;
- probability;
- discrete/continuous random variables;
- confidence-interval intuition later if needed.

## Calculus intuition
**3Blue1Brown — Essence of Calculus**  
https://www.3blue1brown.com/topics/calculus

Use for derivative/chain-rule/gradient intuition.

## Calculus practice/reference
**MIT OCW 18.01SC — Single Variable Calculus**  
https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/

For this phase prioritize:
- derivative definition/rate of change;
- derivative rules;
- chain rule;
- optimization applications.

We are not requiring the full integration curriculum before ML begins.

## Resource discipline
- Watch/read with a notebook and solve problems.
- If a resource becomes too proof-heavy for the current objective, return to the academy depth boundary.
- Never substitute "I watched the playlist" for passing the Phase 1 gate.
## Maintenance metadata
- OpenStax algebra/statistics — **PRACTICE / DURABLE**. Use selected chapters only.
- Mathematics for Machine Learning — **PRIMARY REFERENCE / DURABLE**. Focus on ML-relevant chapters; skip proof depth beyond current gate.
- 3Blue1Brown — **INTUITION / DURABLE**. Never substitute watching for problem solving.
- MIT OCW — **PRACTICE + DEEPER REFERENCE / DURABLE**. Select problems/lectures; do not complete every advanced topic.
