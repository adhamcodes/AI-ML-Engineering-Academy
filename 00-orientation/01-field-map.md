# Module 0.1 — Map the Field

## Goal
Understand the difference between the major AI/ML engineering destinations so you can build a broad trunk before specializing.

## Mental model
Think of modern AI engineering as three overlapping capabilities:

1. **ML science** — data, models, training, statistics, evaluation.
2. **Software engineering** — code quality, APIs, testing, systems, reliability.
3. **AI systems engineering** — LLMs, retrieval, tools, agents, inference, evaluation, deployment.

Specializations emphasize different parts of the same trunk.

## Role map
- **AI Engineer:** broad applied builder of AI-powered systems.
- **ML Engineer:** model/data/training/deployment pipeline emphasis.
- **Applied AI / LLM Engineer:** LLM applications, RAG, evaluation, tool use, inference.
- **Deep Learning Engineer:** neural-network training, architecture, optimization, GPUs.
- **Computer Vision Engineer:** image/video models and systems.
- **NLP Engineer:** language/text systems, increasingly overlapping with LLM engineering.
- **MLOps / ML Platform Engineer:** infrastructure, lifecycle, deployment, observability, reproducibility.
- **Research Engineer:** implementation-heavy bridge between research ideas and functioning systems; stronger theory expectations.

## Active task
For each role, write one sentence answering:
- what is built?
- what must be understood deeply?
- what part of the three-pillar model dominates?

## Checkpoint
Explain why "AI Engineer" is not simply "prompt engineer" and why strong software engineering remains useful even when using pretrained models.
