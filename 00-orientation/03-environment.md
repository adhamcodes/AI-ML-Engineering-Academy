# Module 0.3 — Environment and Working Style

## Goal
Prepare a repeatable environment for experiments and projects.

## Minimum tools
- Python 3
- Git
- a code editor
- terminal/shell
- virtual environments
- Jupyter support for exploration

Later phases add specialized libraries only when needed.

## Required habits
- one environment per project
- dependencies recorded
- secrets kept out of Git
- meaningful commits
- README with reproduction steps
- notebooks used for exploration, scripts/packages used when the work becomes reusable

## Practice
Create a throwaway repository with:
- `README.md`
- `.gitignore`
- a virtual environment
- a tiny Python program
- one notebook
- at least two meaningful commits

Then delete the environment and recreate it from your recorded instructions.

## Gate evidence
Another person should be able to clone the repository and reproduce the tiny project without asking you what you forgot to document.
