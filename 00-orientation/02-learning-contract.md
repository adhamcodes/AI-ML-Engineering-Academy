# Module 0.2 — Learning Contract

## Goal
Set rules that prevent tutorial dependency and false progress.

## Contract
- I will not count watching/reading as mastery.
- I will attempt exercises before searching for solutions.
- I will record recurring mistakes.
- I will use documentation as a normal engineering tool.
- I will respect closed-assistance assessments.
- I will not skip mathematics because a library hides it.
- I will not spend months on mathematics before touching any ML application.
- I will prefer a few strong projects over many toy repositories.
- I will learn durable concepts before framework-specific recipes.

## Exercise
Write three failure modes that could make a learner look productive while learning very little. For each, write one countermeasure.
