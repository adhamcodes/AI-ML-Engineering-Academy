# AI/ML Entry Diagnostic

This is a placement tool, not an exam. Use **closed-assistance** mode for the first attempt.

## A. Python / engineering
1. Write a function that returns the frequency of each word in a list.
2. Explain the difference between a list and a dictionary using one practical example.
3. Read a small traceback and identify the failing line and likely cause.
4. Explain why a virtual environment is useful.
5. Make a Git commit and explain what a commit records.

## B. Algebra / functions
1. Solve `3x + 7 = 22`.
2. If `f(x) = 2x^2 + 1`, compute `f(3)`.
3. Sketch or verbally describe what increasing the slope of a straight line does.
4. Explain what a logarithm roughly represents.

## C. Probability / statistics intuition
1. What does a 70% probability mean and what does it not mean?
2. Explain mean vs median using a skewed-income example.
3. Why can correlation fail to imply causation?
4. What problem occurs if you evaluate a model on the same examples used to fit it?

## D. Data reasoning
Given a table with duplicated rows, missing ages, free-text country names, and a target column, describe the questions you would ask before modeling.

## E. ML intuition
No prior ML knowledge is required. If you already know some, explain:
- overfitting
- classification vs regression
- train/validation/test split

## Placement
- Weak Python/Git: strengthen software foundations while starting Phase 1 slowly.
- Weak math: expected; start Phase 1 from the beginning.
- Strong math: attempt module checkpoints before skipping anything.
- Prior ML experience: you may challenge Phase 3 only after passing its eventual gate.

Record results; do not inflate them.
