# Core Completion Standard

You have completed the broad core only when you can independently:

- frame an ML/AI problem and choose a sensible non-ML baseline;
- prepare and validate data without leakage;
- build, evaluate, and debug classical ML and PyTorch systems;
- explain transformers/LLM fundamentals at engineering depth;
- build an evaluated RAG/LLM system with explicit failure cases;
- design controlled tool-using/agentic workflows and evaluate trajectories;
- package, test, containerize, deploy, observe, and reproduce an AI service;
- reason about cost, latency, security, privacy, data, reliability, and human oversight;
- read an unfamiliar codebase and defend engineering decisions;
- present several serious projects with reproducible evidence.

Specialization continues after this core. “Finished” does not mean “knows everything in AI.”
