# Self-Study Operating System

Use the academy as a stable path, not as a list of topics to search individually.

For each phase:

1. Learn the native lesson.
2. Explain the idea in your own words.
3. Run the matching controlled lab from `LAB_MAP.md`.
4. Predict outcomes before executing.
5. Break or diagnose something realistic.
6. Use tests/evaluators for objective evidence where available.
7. Repair weaknesses.
8. Pass the phase assessment before advancing.

## When stuck

Use this order:

1. inspect data, shapes, metrics, logs, and assumptions,
2. reread the relevant academy section,
3. use the lab hints,
4. consult official documentation,
5. broaden the search only if the problem remains unresolved.

The academy should keep you out of tutorial hopping without preventing you from learning to use documentation.

## Core compute rule

Required labs are designed to be small enough for ordinary CPU-first study. Heavy GPU training is an optional extension, not a graduation requirement.

Keep personal progress and completed solutions outside the canonical curriculum repository using `PROGRESS_TEMPLATE.md`.
