# Curriculum Map

The authoritative phase sequence, durations, outcomes and gates are in **[ROADMAP.md](ROADMAP.md)**.

## Dependency spine
Programming/software-engineering foundation → Math → Data → Classical ML → Deep Learning → Vision/NLP representation foundations → Transformers/LLMs → Applied LLM Engineering → Agents → Production/MLOps → System Design → specialization/career depth.

Career engineering begins early and intensifies after the first employment gates. Do not reorder Transformers before Deep Learning foundations or Agents before evaluation/tool/state fundamentals merely because the current ecosystem makes them easy to demo.
