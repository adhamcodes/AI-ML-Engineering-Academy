# Project Standard

Projects exist to prove capability, not to inflate a portfolio.

## Project ladder
**Exercise → Mini-build → Integration build → Flagship project → Adversarial assessment**

## Every flagship project must document
- Problem and user/stakeholder need
- Requirements and constraints
- Architecture
- Data/input assumptions
- Technical decisions and alternatives considered
- Testing and evaluation
- Failure cases and recovery behavior
- Security/privacy considerations where relevant
- Deployment or reproducibility instructions
- Limitations
- What the learner would improve next

Toy datasets and tutorial clones are acceptable for practice, but should not dominate the final portfolio.
