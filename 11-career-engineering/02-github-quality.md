# Module 11.2 — GitHub Repository Quality

## Capability
Make repositories easy for another engineer to inspect and reproduce.

## Core model
Readable README, setup, architecture, tests/evals, sample outputs, decisions, limitations and clean commit history reduce reviewer uncertainty.

## Practice
Rebuild one README from reviewer perspective.

## Debug / transfer
Test setup on clean environment.

## Evidence to save
One “gold” repository.

## Mastery
A stranger can run/understand it without messaging you.
