# Module 11.4 — Open-Source Contribution

## Capability
Learn unfamiliar codebases and contribute small useful changes.

## Core model
Contribution proves collaboration, codebase navigation and review tolerance. Start with docs/tests/bugs before grand rewrites.

## Practice
Find project, read contribution guide, reproduce issue, submit small change when appropriate.

## Debug / transfer
Handle review request without defensive rewrite.

## Evidence to save
PR/issue trail or local contribution simulation.

## Mastery
You can work inside someone else’s conventions.
