# Module 11.1 — Portfolio Architecture

## Capability
Curate a small set of high-evidence projects aligned to target roles.

## Core model
A portfolio is evidence of judgment and execution, not a museum of tutorials. Every flagship should prove different capability.

## Practice
Audit existing repos against target job requirements.

## Debug / transfer
Remove/label tutorial clones that dilute signal.

## Evidence to save
Portfolio matrix: capability → project → evidence.

## Mastery
A reviewer can see why each repo exists.
