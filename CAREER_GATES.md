# Career Gates

## Gate A — ML Foundation Ready
After Phase 3. You can independently frame, train, validate, debug and explain a classical ML solution. Start ML project/competition/open-source evidence; most modern AI-engineer roles still require more.

## Gate B — Junior Applied AI Ready
After Phase 7. You can build and evaluate a grounded LLM/RAG system with structured outputs, security/failure cases and production-minded Python. Begin serious applications to appropriate junior Applied AI / LLM / AI-enabled backend roles if portfolio and work authorization align.

## Gate C — AI/ML Engineer Ready
After Phase 9. You can test, package, deploy, observe and reproduce end-to-end AI/ML services. Expand targeting to broader ML/AI engineering roles.

## System Design Ready
After Phase 10. You can defend architecture under cost/reliability/security/data constraints.

A gate is permission to **compete**, not a guarantee that the market will hire you.
