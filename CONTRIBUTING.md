# Contributing

Contributions that improve correctness, pedagogy, accessibility, resource freshness, exercises, assessments, or project realism are welcome.

## Before opening a contribution

1. Read `CONSTITUTION.md`, `TEACHING_STANDARD.md`, and `RESOURCE_STANDARD.md`.
2. Preserve prerequisite order and mastery-gate intent.
3. Prefer durable concepts over framework-specific tricks.
4. Do not add a resource simply because it is popular; explain what learning objective it serves.
5. Do not weaken closed-assistance assessments by publishing direct solutions.
6. Never include credentials, private learner data, client data, copyrighted course copies, or proprietary datasets.

## Good contributions

- correct a technical error
- replace a stale or broken resource with an equivalent high-quality source
- improve an unclear explanation
- add a realistic debugging or transfer exercise
- improve accessibility/navigation
- strengthen an assessment without making it arbitrary

## Curriculum changes

For changes that alter prerequisite order, phase gates, or major projects, explain the learning problem being solved and the downstream impact.
