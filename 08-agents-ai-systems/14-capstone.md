# Module 08.14 — Agent Systems Capstone

## Capability
Build a bounded tool-using system that survives adversarial conditions.

## Core model
The capstone combines state, tools, permissions, approval, durable execution, evaluation and observability.

## Practice
Use 2–4 tools on a real task with explicit budgets.

## Debug / transfer
Inject tool outage, malformed tool response, repeated action and prompt injection.

## Evidence to save
Repo with architecture, eval suite, trace examples, runbook and limitations.

## Mastery
System fails safely and you can defend each autonomous boundary.
