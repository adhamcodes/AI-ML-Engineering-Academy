# Module 08.2 — Tool Schemas & Contracts

## Capability
Design tools with narrow typed inputs/outputs and meaningful errors.

## Core model
Tools are APIs exposed to a model. Good contracts reduce ambiguity, permissions and recovery complexity.

## Practice
Design JSON-schema-like tool contracts for search, write and transaction-like actions.

## Debug / transfer
Find dangerous broad tool such as arbitrary shell/database access and narrow it.

## Evidence to save
Tool contract tests and permission notes.

## Mastery
Inputs are validated and side effects explicit.
