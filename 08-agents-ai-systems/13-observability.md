# Module 08.13 — Agent Observability

## Capability
Trace model calls, tool calls, state transitions, latency and cost.

## Core model
Structured traces turn multi-step failures into inspectable evidence and can seed future eval datasets.

## Practice
Instrument a small agent with spans/metadata; inspect slow/error runs.

## Debug / transfer
Redact sensitive data and avoid logging secrets.

## Evidence to save
Trace screenshot/export + incident note.

## Mastery
You can answer where time/cost/failure occurred.
