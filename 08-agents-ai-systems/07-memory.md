# Module 08.7 — Memory & Personalization

## Capability
Separate short-term context, durable facts and retrieval-based memory.

## Core model
Memory should have purpose, provenance, update/delete rules and privacy boundaries; storing everything is not intelligence.

## Practice
Design memory for a coaching/support agent with expiration/source fields.

## Debug / transfer
Repair stale/incorrect memory poisoning future decisions.

## Evidence to save
Memory schema + correction/deletion flow.

## Mastery
You can explain what is remembered, why and for how long.
