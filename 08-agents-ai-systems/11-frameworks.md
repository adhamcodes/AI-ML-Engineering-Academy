# Module 08.11 — Agent Frameworks After Fundamentals

## Capability
Use a framework such as LangGraph/current equivalent without losing architectural understanding.

## Core model
Frameworks can provide graph/state/persistence/streaming primitives. They should implement your design rather than decide it for you.

## Practice
Rebuild one previous loop using framework primitives.

## Debug / transfer
Drop below abstraction to diagnose bad state transition.

## Evidence to save
Side-by-side framework vs minimal implementation note.

## Mastery
You can switch frameworks conceptually.
