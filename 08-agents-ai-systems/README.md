# Phase 8 — Agents & AI Systems

**Typical effort:** ~4–6 weeks

## Purpose
Build controlled tool-using AI systems from durable principles before depending on agent frameworks.

## Modules
1. Workflow vs Agent
2. Tool Schemas & Contracts
3. Agent State
4. Control Loops & Stopping
5. Planning & Decomposition
6. Human-in-the-Loop Approval
7. Memory & Personalization
8. Persistence & Durable Execution
9. Tool Failure & Recovery
10. MCP & Tool/Data Interoperability
11. Agent Frameworks After Fundamentals
12. Agent Evaluation
13. Agent Observability
14. Agent Systems Capstone

## Gate
Pass **Agent Systems Ready** by demonstrating bounded agency, recovery, permissions, human approval and trajectory evaluation.
