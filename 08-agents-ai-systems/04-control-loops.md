# Module 08.4 — Control Loops & Stopping

## Capability
Build bounded observe-decide-act loops with termination criteria.

## Core model
Agent loops require budgets, max steps, success/failure conditions and detection of repeated actions.

## Practice
Implement a tiny tool loop with max steps and repeated-call guard.

## Debug / transfer
Inject a tool loop and make it terminate safely.

## Evidence to save
Loop trace with termination reason.

## Mastery
No task can spin indefinitely without a policy.
