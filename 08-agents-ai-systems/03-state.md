# Module 08.3 — Agent State

## Capability
Represent task state explicitly rather than hiding it in prompt prose.

## Core model
State captures durable facts, progress, pending actions and results; conversation text alone is a poor database.

## Practice
Model a support/research task state machine.

## Debug / transfer
Recover from duplicated/contradictory state updates.

## Evidence to save
Typed state model + transition tests.

## Mastery
You can reconstruct progress after restart.
