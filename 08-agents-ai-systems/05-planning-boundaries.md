# Module 08.5 — Planning & Decomposition

## Capability
Use planning only when task uncertainty benefits from it and keep plans revisable.

## Core model
Plans are hypotheses, not guarantees. Good systems separate planning from permissioned execution and re-plan after evidence.

## Practice
Compare fixed workflow vs generated plan on two tasks.

## Debug / transfer
Detect fabricated plan dependencies and unsupported assumptions.

## Evidence to save
Plan/execute/review trace.

## Mastery
You validate plan steps against available tools/data.
