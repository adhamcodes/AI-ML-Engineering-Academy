# Module 08.1 — Workflow vs Agent

## Capability
Choose deterministic workflows, agentic control, or hybrids based on uncertainty and risk.

## Core model
A workflow encodes known control flow; an agent delegates some next-action selection to a model. Agency increases flexibility and failure surface.

## Practice
Classify ten tasks and defend the simplest sufficient architecture.

## Debug / transfer
Rewrite an over-agentized workflow into deterministic steps plus one bounded model decision.

## Evidence to save
Decision matrix with risk/benefit evidence.

## Mastery
You can say no to an agent and explain why.
