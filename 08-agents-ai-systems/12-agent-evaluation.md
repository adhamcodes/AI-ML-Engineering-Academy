# Module 08.12 — Agent Evaluation

## Capability
Evaluate trajectories, tool selection, arguments, recovery and final outcomes.

## Core model
Final-answer quality can hide dangerous/inefficient paths. Agent eval includes intermediate behavior and task success.

## Practice
Build an eval set with expected tool use/forbidden actions/max-step constraints.

## Debug / transfer
Catch correct answer produced through wrong/unsafe tool call.

## Evidence to save
Trajectory scorers + failure taxonomy.

## Mastery
You measure behavior, not vibes.
