# Module 10.1 — Requirements & Success Metrics

## Capability
Translate ambiguous product language into measurable technical/user outcomes.

## Core model
Good design begins with user decision/workflow, baseline, constraints, failure costs, data availability and measurable success.

## Practice
Turn three vague requests (“add AI”) into clear problem statements.

## Debug / transfer
Identify metric that rewards wrong behavior.

## Evidence to save
One-page product/AI design brief.

## Mastery
You can state what success and unacceptable failure mean.
