# Module 10.9 — Architecture Communication & ADRs

## Capability
Communicate systems clearly enough for review and future change.

## Core model
Architecture diagrams show components/flows/trust boundaries; ADRs preserve context, considered options, decision and consequences.

## Practice
Write one C4-ish component diagram and two ADRs.

## Debug / transfer
Review a diagram that hides data/side-effect boundaries.

## Evidence to save
Architecture package.

## Mastery
A new engineer can understand the system without oral history.
