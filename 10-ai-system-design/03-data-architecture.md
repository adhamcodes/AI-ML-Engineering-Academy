# Module 10.3 — Data Architecture

## Capability
Design sources, ingestion, storage, labeling, retrieval and feedback around the AI system.

## Core model
AI quality is bounded by data provenance, freshness, permissions and lifecycle.

## Practice
Map data flow and ownership for an AI support system.

## Debug / transfer
Detect training-serving skew or unauthorized retrieval source.

## Evidence to save
Data-flow diagram + data contract list.

## Mastery
Every data element has source, owner and use.
