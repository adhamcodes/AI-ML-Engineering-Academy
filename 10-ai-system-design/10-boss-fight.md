# Module 10.10 — System Design Boss Fight

## Capability
Defend a complete design for an ambiguous AI product under changing constraints.

## Core model
Professional design means making explicit assumptions, alternatives and tradeoffs, then revising when constraints change.

## Practice
Given a messy business scenario, ask clarifying questions, baseline alternatives, design data/model/eval/ops/security.

## Debug / transfer
Mid-assessment constraints change: stricter privacy, half latency budget, provider outage.

## Evidence to save
Design doc + verbal/written defense + revision.

## Mastery
Pass if reasoning remains coherent under change.
