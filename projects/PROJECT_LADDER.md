# Project Ladder

Projects exist to prove capability, not fill GitHub.

1. **Messy Data Investigation** — raw data → quality audit → EDA → reproducible report.
2. **Classical ML Flagship** — unfamiliar tabular problem → baseline → clean validation → error analysis → technical report.
3. **Deep Learning Repair Project** — diagnose and fix a broken PyTorch training system.
4. **Representation Comparison** — compare simple vs learned vision/text representations.
5. **Tiny Transformer Lab** — implement/test core attention/transformer pieces.
6. **Evaluated Applied LLM System** — RAG/structured output/eval/security/cost evidence.
7. **Controlled Agent System** — tools/state/approval/recovery/trajectory evals.
8. **Production AI Service** — API + Docker + tests/evals + CI + observability + runbook.
9. **AI System Design Boss Fight** — architecture under changing requirements.

## Portfolio selection
Do not publish all nine as equal flagship work. By application time, polish 3–5 that best prove your target role and keep smaller projects as supporting evidence.
