# Module 04.11 — Regularization & Generalization

## Capability
Use weight decay, dropout, early stopping and data augmentation as hypotheses to test.

## Mental model / core ideas
Regularization changes effective capacity or training signals to improve generalization; it is not a substitute for fixing leakage or bad splits.

## Practice
Compare no regularization vs weight decay/dropout/augmentation on controlled runs.

## Debugging / transfer task
A model overfits: design an ordered investigation rather than stacking every regularizer.

## Build evidence
Produce an overfitting diagnosis memo with experiments.

## Mastery check
Separate data, capacity, optimization and regularization causes.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
