# Module 04.16 — Experiment Tracking

## Capability
Compare experiments systematically instead of remembering notebook outputs.

## Mental model / core ideas
An experiment is a hypothesis plus code/data/config/metrics/artifacts. Tracking is useful only if runs are comparable and named meaningfully.

## Practice
Track controlled runs manually or with MLflow; log parameters, metrics and artifacts.

## Debugging / transfer task
Identify a misleading comparison where more than one variable changed.

## Build evidence
Produce a small experiment table and decision record.

## Mastery check
You can answer what changed, why, and what evidence supported the next decision.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
