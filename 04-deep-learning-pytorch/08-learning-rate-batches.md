# Module 04.8 — Learning Rate, Batches & Schedules

## Capability
Reason about step size, gradient noise and schedules.

## Mental model / core ideas
Batch size changes gradient estimate noise and compute behavior; learning rate controls update scale. Their interaction influences stability and speed.

## Practice
Train the same network under several LR/batch combinations and record curves.

## Debugging / transfer task
Given diverging/flat/noisy curves, propose a test sequence before random hyperparameter search.

## Build evidence
Create a small LR-range experiment and decision note.

## Mastery check
You can diagnose at least three distinct curve patterns.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
