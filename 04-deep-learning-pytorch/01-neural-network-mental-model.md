# Module 04.1 — Neural Networks as Function Approximators

## Capability
Explain what layers, parameters, activations and predictions represent without mystical language.

## Mental model / core ideas
A network is a composition of parameterized functions. Training changes parameters so outputs reduce a chosen loss on observed data; generalization is the goal, not memorization.

## Practice
Draw a tiny dense network and compute one forward pass by hand for simple numbers.

## Debugging / transfer task
Compare two networks that fit training data equally well; identify why capacity alone does not guarantee useful generalization.

## Build evidence
Write a NumPy-only forward pass for a 2-layer network and annotate shapes.

## Mastery check
Given an architecture, predict tensor shapes and explain every parameter group.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
