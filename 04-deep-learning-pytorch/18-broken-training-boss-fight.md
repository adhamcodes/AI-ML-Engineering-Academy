# Module 04.18 — Broken Training System — Boss Fight

## Capability
Diagnose a multi-defect PyTorch project independently.

## Mental model / core ideas
Professional competence means turning symptoms into hypotheses, running discriminating tests, and fixing root causes without random rewrites.

## Practice
Closed-assistance assessment: inspect data, split, model, loop, metrics and environment. Maintain an investigation log.

## Debugging / transfer task
Injected defects include leakage, wrong labels/shapes, train/eval misuse, bad LR and a checkpoint/repro issue.

## Build evidence
Submit repaired repo, tests, before/after curves and root-cause report.

## Mastery check
Pass only if fixes are explained and the repaired system generalizes under a clean evaluation.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
