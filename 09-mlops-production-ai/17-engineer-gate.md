# Module 09.17 — Employment Gate — AI/ML Engineer Ready

## Capability
Demonstrate end-to-end production judgment on an unfamiliar system.

## Core model
The gate combines codebase navigation, debugging, deployment, evals and tradeoff communication.

## Practice
Repair/deploy a partially complete AI service with a new requirement.

## Debug / transfer
Hidden tests include data contract, quality regression and operational failure.

## Evidence to save
Technical handover + architecture decision record.

## Mastery
Pass earns **AI/ML Engineer Ready** for broad junior/early-career targeting, subject to portfolio/interview evidence.
