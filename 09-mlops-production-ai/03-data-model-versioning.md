# Module 09.3 — Data & Model Versioning

## Capability
Version inputs/artifacts according to reproducibility and rollback needs.

## Core model
Large data/models need identity and storage strategy, not necessarily Git blobs. Checksums, object versions/registries and metadata link artifacts to runs.

## Practice
Create dataset fingerprint and model artifact version workflow.

## Debug / transfer
Recover after wrong model/data combination.

## Evidence to save
Version manifest and rollback note.

## Mastery
You can identify exactly what is deployed.
