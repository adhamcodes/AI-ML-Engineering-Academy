# Module 09.5 — Packaging & Configuration

## Capability
Turn notebooks/scripts into maintainable packages/services.

## Core model
Production code separates domain logic, interfaces, configuration and side effects; notebooks remain exploration tools.

## Practice
Refactor a notebook into package + CLI/service modules.

## Debug / transfer
Find circular config/import/global-state problems.

## Evidence to save
Installable/runnable project with documented config.

## Mastery
Core logic is testable without network/UI.
