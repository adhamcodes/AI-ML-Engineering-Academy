# Module 09.4 — Testing ML/AI Systems

## Capability
Test code, data contracts, model behavior and system integration.

## Core model
ML tests include deterministic code tests plus data assumptions, invariants, thresholds, regression/eval sets and integration boundaries.

## Practice
Write unit/data/model/e2e tests for a small pipeline.

## Debug / transfer
Catch a model that “runs” but violates minimum quality/subgroup contract.

## Evidence to save
Test suite organized by failure type.

## Mastery
Deployment can fail automatically on meaningful regression.
