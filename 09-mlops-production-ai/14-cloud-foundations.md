# Module 09.14 — Cloud Foundations for AI Engineers

## Capability
Understand compute/storage/network/IAM primitives without memorizing one cloud catalog.

## Core model
Cloud architecture composes virtual compute, managed storage/database, object storage, networking, identity/secrets and observability.

## Practice
Map local service architecture to AWS/Azure/GCP equivalents.

## Debug / transfer
Spot public bucket/overprivileged identity/egress-cost risk.

## Evidence to save
Provider-neutral architecture diagram.

## Mastery
You can learn a specific cloud from docs using primitives.
