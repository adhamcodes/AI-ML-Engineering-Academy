# Module 09.9 — CI/CD for ML/AI

## Capability
Automate quality gates and release steps.

## Core model
CI validates changes; delivery/deployment promotes artifacts after tests/evals. ML/AI pipelines may gate on data/model/eval quality as well as code tests.

## Practice
Create CI pipeline running unit/integration/eval smoke tests.

## Debug / transfer
Prevent accidental deployment after failed eval.

## Evidence to save
Workflow file + branch/release policy.

## Mastery
Release criteria are machine-checkable.
