# Module 09.1 — Reproducible Environments

## Capability
Make runtime dependencies/configuration reconstructable.

## Core model
Reproducibility requires code version, dependency environment, configuration, data/model identity and execution instructions.

## Practice
Recreate a project in a clean environment.

## Debug / transfer
Find hidden local dependency or untracked configuration.

## Evidence to save
Lock/dependency file + clean setup test.

## Mastery
A second machine can run the core workflow.
