# Phase 3 Resource Map

## Primary practical course
**Machine Learning in Python with scikit-learn — Inria / scikit-learn developers**  
https://inria.github.io/scikit-learn-mooc/

This is the main hands-on companion. It is free, self-paced, continuously updated for current scikit-learn, and explicitly teaches critical predictive-pipeline design rather than only API recipes.

## Primary conceptual text
**An Introduction to Statistical Learning with Applications in Python (ISLP)**  
https://www.statlearning.com/

Use selected chapters/labs for regression, classification, resampling, regularization, trees, SVMs, and unsupervised learning. The authors provide a downloadable Python edition and companion resources.

## Official reference
**scikit-learn User Guide**  
https://scikit-learn.org/stable/user_guide.html

High-value sections:
- model selection/cross-validation;
- metrics/scoring;
- pipelines/composite estimators;
- preprocessing/imputation;
- inspection;
- common pitfalls/recommended practices.

## Resource rule
The academy determines order and mastery. Do not mechanically finish every book/course chapter before doing projects.
## Maintenance metadata
- scikit-learn MOOC — **PRIMARY + PRACTICE / REVIEW YEARLY**. Use the continuously updated self-paced materials and exercises.
- ISLP — **PRIMARY CONCEPTUAL / DURABLE**. Use selected chapters/labs; no need to finish survival analysis/multiple testing during core Phase 3.
- scikit-learn User Guide — **REFERENCE / REVIEW YEARLY**. Prioritize model selection, metrics, pipelines, preprocessing, inspection, and pitfalls.
