# Module 3.20 — Experiment Design and Model Comparison

## Capability
Run controlled experiments where changes are attributable and results are recorded reproducibly.

For each experiment record:
- hypothesis;
- data/split version;
- pipeline/model configuration;
- primary/secondary metrics;
- runtime/compute notes;
- result;
- interpretation;
- next decision.

Compare against the same validation protocol. Avoid changing dataset, preprocessing, metric, model, and split simultaneously then guessing what helped.

## Practice
Run a five-experiment ladder from baseline → preprocessing → model family → feature change → threshold decision.

## Mastery
Your experiment log tells a coherent story of decisions.
