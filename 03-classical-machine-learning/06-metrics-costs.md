# Module 3.6 — Metrics and Asymmetric Error Costs

## Capability
Choose metrics based on decision costs and class distribution.

Classification: confusion matrix, precision, recall, specificity awareness, F1, ROC-AUC, precision-recall curves, log loss where appropriate.

Regression: MAE, MSE/RMSE, R² with caveats.

Accuracy can be useless with severe imbalance. A metric is not "good" in isolation; it must reflect the task.

## Practice
For disease screening, spam filtering, and fraud review, rank false-positive vs false-negative cost and choose an evaluation set of metrics.

## Mastery
You can defend a primary metric in stakeholder language.
