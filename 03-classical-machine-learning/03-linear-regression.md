# Module 3.3 — Linear Regression

## Capability
Understand linear prediction, coefficients, residuals, squared loss, assumptions/limitations, and scikit-learn implementation.

Model:
`ŷ = β0 + β1x1 + ... + βpxp`

Coefficients represent conditional linear associations within the model—not automatic causal effects.

Evaluate residual patterns and outliers, not only one score.

## Practice
Fit a baseline linear model, inspect coefficients, plot residuals, compare MAE/RMSE, and identify where linearity is visibly inadequate.

## Mastery
You can explain what the model assumes and when a good average score hides bad subgroup behavior.
