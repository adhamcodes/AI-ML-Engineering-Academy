# Module 3.13 — Gradient Boosting

## Capability
Understand sequential additive ensembles that fit new learners to remaining errors/gradients.

Boosting differs from bagging: learners are built sequentially to correct current mistakes.

Important controls include learning rate, number of estimators, tree complexity, subsampling/regularization depending on implementation.

## Practice
Compare a histogram/gradient boosting model to random forest and linear baseline on tabular data. Tune only a small justified set of parameters with CV.

## Mastery
You can explain the sequential correction idea and recognize overfitting/compute tradeoffs.
