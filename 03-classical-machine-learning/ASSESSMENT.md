# Phase 3 Boss Assessment — ML Foundation Ready

**Mode:** closed-solution assistance for core modeling. Official documentation allowed.

You receive a dirty unfamiliar tabular dataset plus a vague stakeholder objective. It includes at least one leakage trap, class/target challenge, misleading baseline opportunity, and subgroup issue.

## Tasks
- reframe the objective and choose metric(s);
- create defensible splits;
- identify leakage before modeling;
- build baseline + pipeline;
- compare at least three model families using one consistent protocol;
- tune minimally and honestly;
- choose threshold if classification requires it;
- analyze errors/subgroups;
- freeze choices and evaluate once on held-out test;
- write a short decision memo.

## Oral defense
Explain why your preferred model won, one reason the measured performance may fail in deployment, and one next data experiment more valuable than hyperparameter tuning.

## Pass
A lower score with correct methodology can pass. A spectacular leaked score fails.
