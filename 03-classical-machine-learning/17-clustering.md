# Module 3.17 — Clustering

## Capability
Use clustering as exploratory structure discovery without pretending unsupervised groups are automatically real-world "segments."

Core intuition:
- k-means minimizes within-cluster squared distances around centroids;
- scaling and k choice matter;
- cluster shape assumptions can be wrong.

## Practice
Cluster a dataset under different scaling/k choices, visualize when possible, and test stability/interpretability. Create a case where k-means fails on non-spherical structure.

## Mastery
You treat clusters as hypotheses requiring validation, not ground-truth labels.
