# Phase 3 Flagship — Unfamiliar Tabular ML System

Choose a non-toy regression or classification problem you have not previously solved.

## Required workflow
1. stakeholder/problem framing;
2. leakage-safe unit/time definition;
3. meaningful baseline;
4. train/validation/test strategy;
5. preprocessing pipeline;
6. at least three justified model families;
7. cross-validation/model selection;
8. error/subgroup analysis;
9. final frozen test evaluation;
10. limitations and deployment risks.

## Repository evidence
`README`, data card/source, reproducible pipeline, tests/checks, experiment log, technical report, model card-style limitations, environment file.

## Forbidden
- tuning against test set;
- reporting only accuracy/R²;
- preprocessing before split when it learns from data;
- unexplained Kaggle notebook copy;
- hiding failed experiments.
