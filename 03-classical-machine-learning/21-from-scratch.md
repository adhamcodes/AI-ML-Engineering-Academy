# Module 3.21 — Selected Algorithms from Scratch

## Capability
Implement simplified versions to expose mechanics, then return to trustworthy libraries for production work.

Implement with NumPy/small data:
- linear regression with gradient descent;
- logistic regression with sigmoid + log-loss intuition;
- k-NN;
- a tiny decision-stump/tree-split exercise.

Requirements:
- tests on tiny known cases;
- compare predictions to scikit-learn qualitatively/numerically where appropriate;
- document numerical/efficiency limitations.

## Mastery
You understand what `fit()` is doing conceptually without believing your educational implementation should replace scikit-learn.
