# Module 3.5 — Logistic Regression and Classification

## Capability
Understand probabilistic binary classification, decision thresholds, log-odds intuition, and why class labels lose information.

Logistic regression transforms a linear score into probability-like output through the sigmoid function under the model.

Prediction threshold is a **decision policy**, not a law fixed at 0.5.

## Practice
Fit logistic regression, inspect predicted probabilities, vary threshold, and measure how false positives/negatives change.

## Mastery
You separate model score/probability estimation from downstream decision threshold.
