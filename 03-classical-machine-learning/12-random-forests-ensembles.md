# Module 3.12 — Random Forests and Ensemble Intuition

## Capability
Explain how combining diverse models can reduce variance and improve robustness.

Random forests train many randomized trees using resampled data/features and aggregate predictions.

Key intuition: many imperfect but not-identical models can average out individual instability.

## Practice
Compare single tree vs random forest on repeated splits. Measure stability and compute/performance tradeoff.

## Mastery
You can explain why "more trees" is not the same as "deeper one tree."
