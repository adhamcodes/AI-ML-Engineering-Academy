# Phase 3 — Classical Machine Learning

**Expected effort:** ~6–8 weeks.

## Purpose
Learn predictive modeling as an experimental discipline: define the problem, establish baselines, split data correctly, preprocess without leakage, choose metrics aligned to costs, compare models, analyze errors, and communicate limitations.

## Modules
1. problem framing and baselines
2. train/validation/test design
3. linear regression
4. regularization
5. logistic regression/classification
6. metrics and asymmetric costs
7. preprocessing + pipelines
8. feature engineering
9. cross-validation
10. data leakage
11. decision trees
12. random forests/ensembles
13. gradient boosting
14. k-nearest neighbors
15. SVM intuition
16. imbalance and calibration
17. clustering
18. PCA/dimensionality reduction
19. interpretability/error analysis
20. experiment design and model comparison
21. selected from-scratch implementations
22. flagship project
23. boss assessment

## Employment Gate A
Passing this phase earns **ML Foundation Ready**. It does not yet equal modern AI-engineer readiness.
