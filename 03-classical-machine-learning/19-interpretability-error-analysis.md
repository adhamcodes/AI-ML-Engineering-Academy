# Module 3.19 — Interpretability and Error Analysis

## Capability
Investigate how a model behaves, where it fails, and whether performance differs across meaningful subgroups.

Tools can include:
- coefficients where valid;
- tree inspection;
- permutation importance;
- partial-dependence style analysis with caveats;
- confusion/error slices;
- residual plots;
- manual inspection of high-confidence errors.

Feature importance is not causal explanation.

## Practice
Create an error-analysis report: worst errors, subgroup metrics, suspicious features, examples near decision threshold, and three hypotheses for improvement.

## Mastery
Your next experiment follows evidence from errors, not random hyperparameter searching.
