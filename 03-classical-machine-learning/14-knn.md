# Module 3.14 — k-Nearest Neighbors and Distance Methods

## Capability
Understand instance-based prediction, distance, scaling sensitivity, neighborhood size, and curse-of-dimensionality intuition.

k-NN stores training examples and predicts from nearby points. Feature scale strongly affects distance.

Small k → flexible/high variance. Large k → smoother/higher bias.

## Practice
Run k-NN with and without scaling; vary k; create a toy high-dimensional example and discuss why distances become less discriminative.

## Mastery
You recognize when distance has meaningful geometry and when it does not.
