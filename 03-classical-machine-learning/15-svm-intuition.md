# Module 3.15 — Support Vector Machine Intuition

## Capability
Understand maximum-margin classification, support vectors, regularization tradeoffs, and kernel idea at a practical level.

A linear SVM seeks a separating boundary with a large margin. Only key boundary examples (support vectors) determine the solution strongly.

Kernel methods allow nonlinear boundaries through implicit feature-space similarity, but scaling and hyperparameters matter.

## Depth boundary
No full dual-optimization derivation required for core track.

## Practice
Compare linear SVM/logistic regression on scaled data; then use an RBF kernel on a nonlinear toy dataset.

## Mastery
You can explain margin and why kernel SVMs may become expensive on large datasets.
