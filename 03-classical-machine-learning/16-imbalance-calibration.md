# Module 3.16 — Class Imbalance and Calibration

## Capability
Separate ranking/discrimination from probability calibration and choose strategies for rare outcomes.

Do not "solve" imbalance by blindly oversampling. Start with metric/threshold/cost design.

Options can include class weighting, resampling, threshold tuning, appropriate metrics, and data collection.

Calibration asks whether predicted probabilities correspond to observed frequencies (e.g., among predictions near 0.8, roughly 80% positive under suitable conditions).

## Practice
Evaluate a rare-event model with accuracy, PR curve, threshold table, and calibration plot. Explain different questions each answers.

## Mastery
You can choose actions based on business cost rather than class ratio alone.
