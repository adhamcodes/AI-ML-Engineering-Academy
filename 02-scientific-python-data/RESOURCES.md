# Phase 2 Resource Map

## NumPy
**NumPy User Guide**  
https://numpy.org/doc/stable/user/

Focus on array creation, indexing, shape, dtypes, operations, broadcasting, copies/views, and random fundamentals. The official guide documents broadcasting as a mechanism for vectorized operations with compatible shapes.

## pandas
**pandas User Guide**  
https://pandas.pydata.org/docs/user_guide/

Start with:
- 10 minutes to pandas;
- data structures;
- indexing/selecting;
- missing data;
- merge/join/concatenate;
- groupby;
- time series;
- IO.

Use API reference only when you need exact function behavior.

## Visualization
**Matplotlib documentation/tutorials**  
https://matplotlib.org/stable/tutorials/index.html

Use for plotting mechanics. The academy, not the plotting library, defines which analytical questions you should ask.

## SQL
**PostgreSQL Current Tutorial**  
https://www.postgresql.org/docs/current/tutorial.html

Focus on tables, querying, joins, aggregates, updates awareness, foreign keys, transactions, and window functions selectively.

## Resource discipline
Do not try to memorize every DataFrame method. Learn to inspect data, formulate transformations, and consult current official docs.
## Maintenance metadata
- NumPy — **PRIMARY REFERENCE / REVIEW YEARLY**. Concepts of arrays/vectorization/broadcasting are durable; API details can evolve.
- pandas — **PRIMARY REFERENCE / REVIEW YEARLY**. Focus on core tabular operations and data-quality reasoning, not method memorization.
- Matplotlib — **REFERENCE / REVIEW YEARLY**. Learn plotting mechanics only as needed for analysis.
- PostgreSQL tutorial — **PRACTICE + REFERENCE / REVIEW YEARLY**. SQL/relational concepts are durable; version-specific features can change.
