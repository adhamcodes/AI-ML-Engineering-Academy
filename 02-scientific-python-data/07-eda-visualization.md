# Module 2.7 — Exploratory Data Analysis and Visualization

## Capability
Use summaries and plots to discover data quality, distribution, relationships, subgroups, and suspicious patterns—without turning exploration into a hunt for pretty charts.

Start with questions:
- What is the unit of observation?
- What is missing?
- Which values are impossible/suspicious?
- Are there duplicates?
- How are targets/classes distributed?
- Are features highly skewed?
- Are there temporal/group effects?
- Could any variable leak the answer?

Useful visual families:
- histogram/density for distributions;
- box/violin style summaries for spread/outliers;
- scatter for numeric relationships;
- bar/count for categories;
- time series for temporal behavior.

## Practice
Produce five plots for a dataset, but require each caption to state **what decision/question the plot informs**. Delete plots that do not answer anything.

## Mastery
Your EDA ends with hypotheses/data-quality actions, not a gallery.
