# Module 2.1 — NumPy Arrays and Shape Reasoning

## Capability
Use NumPy arrays for numerical data and predict shapes/dtypes before running operations.

Python lists are general containers. NumPy arrays are specialized for homogeneous numerical computation and multi-dimensional operations.

Key ideas:
- `shape` — dimensions;
- `ndim` — number of axes;
- `dtype` — element representation;
- slicing/indexing;
- axis-aware reductions.

## ML connection
Datasets, model weights, images, embeddings, and batches are all naturally represented as arrays/tensors. Shape literacy is non-negotiable.

## Practice
Create a `(4,3)` array. Predict and verify shapes of:
- one row;
- one column;
- first two rows;
- mean over axis 0;
- mean over axis 1.

Explain what each reduction would mean if rows are customers and columns are features.

## Mastery
You predict shape and semantic meaning before executing code.
