# Phase 2 Mastery Assessment — Data Readiness

**Mode:** closed-solution assistance for the core transformation portion. Official docs are allowed.

You receive an unfamiliar dataset package containing at least two tables, missing values, duplicates, inconsistent categories, and time fields.

## Tasks
1. define unit of observation and target question;
2. profile data before cleaning;
3. identify at least five concrete quality risks;
4. join tables while proving expected cardinality;
5. create two grouped summaries;
6. write at least one SQL query if a database fixture is supplied;
7. create three purposeful plots;
8. produce a reproducible cleaned dataset;
9. identify possible leakage and sampling bias;
10. rerun from a clean process and reproduce outputs.

## Defense
Explain one choice you intentionally did **not** make and why.

## Pass
Correct code alone is insufficient. You must demonstrate reliable shape/cardinality reasoning and domain-aware data decisions.
