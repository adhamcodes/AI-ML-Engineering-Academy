# Phase 2 — Scientific Python & Data

**Expected effort:** roughly 3–4 weeks.

## Purpose
Turn Python skill into numerical/data-analysis capability. You should leave able to inspect an unfamiliar dataset, identify quality problems, transform it reproducibly, query relational data, and produce an honest exploratory report without accidentally leaking future information.

## Modules
1. NumPy arrays and shape reasoning
2. vectorization and broadcasting
3. numerical pitfalls and reproducibility
4. pandas/DataFrames and indexing
5. missing/categorical/time data
6. joins, grouping, reshaping
7. EDA and visualization
8. SQL and relational thinking
9. notebooks vs scripts and reproducible analysis
10. messy-data flagship project + mastery assessment
