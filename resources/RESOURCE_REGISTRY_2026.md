# Resource Registry — reviewed 2026-08-29

The academy never requires buying a course. Use resources selectively according to phase files.

| Resource | Role | Freshness | Use |
|---|---|---|---|
| Mathematics for Machine Learning — https://mml-book.github.io/ | Primary/reference | Durable | linear algebra, calculus, probability, optimization foundations |
| MIT OCW 18.06 — https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/ | Practice/deep dive | Durable | rigorous linear-algebra lectures/problems |
| Google ML Crash Course — https://developers.google.com/machine-learning/crash-course | Secondary/practice | Review yearly | interactive ML fundamentals/problem framing |
| scikit-learn MOOC — https://inria.github.io/scikit-learn-mooc/ | Primary | Review yearly | practical classical ML and pipeline methodology |
| ISL with Python — https://www.statlearning.com/ | Primary/reference | Durable | statistical-learning concepts + Python labs |
| PyTorch Tutorials — https://docs.pytorch.org/tutorials/beginner/basics/intro.html | Primary | Review yearly | tensors, data, models, autograd, optimization, save/load |
| fast.ai — https://course.fast.ai/ | Optional applied deep dive | Review yearly | project-heavy deep learning |
| Hugging Face LLM Course — https://huggingface.co/learn/llm-course/en/chapter1/1 | Primary | Fast-moving | Transformers, datasets, tokenizers, fine-tuning ecosystem |
| Stanford CS336 — https://cs336.stanford.edu/ | Advanced deep dive | Review yearly | language modelling from scratch, systems/training depth |
| Anthropic Building Effective Agents — https://www.anthropic.com/engineering/building-effective-agents | Concept reference | Fast-moving | simple composable agent/workflow patterns |

| LangGraph docs — https://docs.langchain.com/oss/python/langgraph/overview | Implementation option | Fast-moving | stateful/durable agent orchestration after fundamentals |
| Made With ML — https://madewithml.com/courses/mlops/ | Primary/secondary | Review yearly | testing, reproducibility, serving, CI/CD, monitoring |
| MLflow — https://mlflow.org/docs/latest/ | Reference/practice | Fast-moving | experiment tracking, models, GenAI tracing/evaluation |
| FastAPI — https://fastapi.tiangolo.com/tutorial/ | Primary/reference | Review yearly | Python service/API delivery |
| Docker Get Started — https://docs.docker.com/get-started/ | Primary/reference | Review yearly | container fundamentals |
| vLLM — https://docs.vllm.ai/en/stable/ | Advanced reference | Fast-moving | open-model serving/inference |

| NIST AI RMF — https://www.nist.gov/itl/ai-risk-management-framework | Risk/governance reference | Durable/review | trustworthiness and risk-management framing |

## Rule
Framework/API tutorials are implementation references, not the curriculum's conceptual spine. If a tool changes, replace the resource without deleting the underlying capability.
