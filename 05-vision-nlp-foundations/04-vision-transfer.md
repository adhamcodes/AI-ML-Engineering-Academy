# Module 05.4 — Vision Transfer Learning

## Capability
Use pretrained vision models responsibly.

## Mental model / core ideas
Pretrained representations can reduce data/compute needs; domain shift and preprocessing compatibility determine benefit.

## Practice
Fine-tune a small pretrained model; compare frozen vs partial/full tuning.

## Debugging / transfer task
Find failure caused by label leakage or mismatched transforms.

## Build evidence
Produce a transfer-learning experiment report.

## Mastery check
Explain baseline, transfer gain and limitations.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
