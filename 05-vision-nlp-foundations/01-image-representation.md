# Module 05.1 — Images as Tensors

## Capability
Connect pixels/channels/spatial structure to model inputs and transformations.

## Mental model / core ideas
Images are structured arrays; spatial locality and channel semantics make generic dense treatment inefficient.

## Practice
Inspect shapes/ranges/channel order; visualize transformations and normalization.

## Debugging / transfer task
Diagnose channel-order/range/preprocessing mismatch.

## Build evidence
Build a tiny image-input sanity-check pipeline.

## Mastery check
Explain how preprocessing affects what a pretrained model sees.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
