# Module 05.5 — Vision Evaluation & Error Analysis

## Capability
Evaluate beyond aggregate accuracy and inspect visual failure modes.

## Mental model / core ideas
Confusion patterns, class imbalance, subgroup behavior, calibration and data quality can matter more than one score.

## Practice
Build confusion matrix/per-class metrics and manually inspect high-confidence errors.

## Debugging / transfer task
Detect duplicate images across splits or shortcut/background features.

## Build evidence
Create an error gallery with hypotheses and follow-up tests.

## Mastery check
Connect errors to data/model decisions.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
