# Module 05.3 — CNN Architecture Patterns

## Capability
Read and modify simple CNNs while reasoning about representation depth.

## Mental model / core ideas
Early layers tend to capture local patterns; deeper stacks combine them into broader representations. Pooling/stride trade resolution for abstraction/compute.

## Practice
Build a small CNN and compare against an MLP baseline.

## Debugging / transfer task
Investigate overfitting vs underfitting and bad normalization/augmentation.

## Build evidence
Create an architecture diagram with tensor shapes.

## Mastery check
Defend architecture changes with measurements.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
