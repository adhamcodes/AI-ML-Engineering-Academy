# Module 05.2 — Convolution & Local Features

## Capability
Explain kernels, receptive fields, stride and padding.

## Mental model / core ideas
Convolution reuses local filters across space, creating translation-sensitive feature maps with fewer parameters than dense connections.

## Practice
Compute a tiny 2D convolution by hand and trace output size.

## Debugging / transfer task
Repair an architecture with unintended spatial collapse.

## Build evidence
Implement a tiny convolution operation in NumPy or inspect PyTorch Conv2d outputs.

## Mastery check
Predict feature-map shapes and receptive-field intuition.

**Rule:** if you can execute the recipe but cannot explain the failure modes or adapt it to a different dataset/system, keep practicing.
