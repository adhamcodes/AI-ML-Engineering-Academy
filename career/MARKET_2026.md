# 2026 Market Snapshot — AI/ML Engineering

This file is a directional snapshot, not a promise that a specific job will remain open.

## Repeated signals in current roles
Current junior/applied AI postings increasingly combine:
- production-quality Python;
- SQL/relational data;
- messy data ingestion/normalization;
- LLM/RAG/embeddings/tooling;
- output validation, grounding, guardrails, and systematic evaluation;
- cost/latency awareness;
- APIs/cloud/deployment;
- ability to read and extend unfamiliar code.

This is why the academy treats software engineering, evaluation, and production work as core—not optional appendices.

## Degree reality
Some Canadian junior roles still make a degree mandatory. Others explicitly accept self-taught/bootcamp/career-switcher candidates and emphasize projects/curiosity. A no-degree learner should assume the burden of proof is higher and build inspectable evidence rather than relying on course completion.

## Evidence strategy
By the serious application stage, maintain several repositories showing:
1. reproducible classical ML work with leakage/error analysis;
2. a PyTorch system you can debug and explain;
3. an evaluated LLM/RAG system;
4. a controlled tool-using/agentic system;
5. at least one production/deployment project.

Add technical writing and, when possible, contributions to unfamiliar/open-source codebases.
