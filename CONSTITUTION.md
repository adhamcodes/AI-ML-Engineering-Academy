# Constitution

This repository is a self-guided academy, not a checklist or link dump.

## Non-negotiable principles

1. **Capability over completion.** Finishing a resource is not evidence of mastery.
2. **Assume intelligence, not prior knowledge.** New technical terms must be explained before they are used as prerequisites.
3. **Why before how, where useful.** Mental models matter.
4. **Active learning.** Every major concept should lead to prediction, tracing, explanation, debugging, reconstruction, implementation, or transfer.
5. **Progressive independence.** Scaffolding must decrease as the learner advances.
6. **Debugging is core curriculum.** Learners must repair broken systems, not only build from clean examples.
7. **Transfer matters.** Assessments should require applying ideas in unfamiliar settings.
8. **Durable concepts before frameworks.** Teach the underlying mechanism, then show current tools.
9. **Resources are curated ruthlessly.** Usually one primary resource, one practice resource, one reference, and optional deep dives.
10. **No dependency on ChatGPT.** Core progression must remain usable with the repository, a browser, Git, a code editor, and the listed resources.
11. **No fake timelines or guarantees.** Durations are estimates; gates are capability-based.
12. **No project spam.** Every project must prove specific competencies.
13. **Assessment integrity.** Some gates are explicitly closed-assistance; later professional projects may allow AI but require review, testing, and understanding.
14. **Version-aware.** Durable foundations and fast-moving ecosystem material must be clearly distinguished.
